## 📜 About the Project

This project was born from my desire to learn [LÖVE2D](https://love2d.org/) and game development using Lua. The reality? It's a humble project, built with a lot of
struggle. I spend hours fixing bizarre bugs, hunting down syntax errors, and trying to figure out why the main character decided to walk through a wall and live in the void.

Don't expect a masterpiece. It's just a dev fighting the engine and celebrating every time a sprite loads without crashing the game.

The BG image was made using AI, because at least one thing should be easy. Monsters don't have alpha channel and don't fight; you just stay in front of each other.
Maybe kiss, I don't know.

## ✨ "Features" (or what works so far)

- [x] The game actually compiles and runs.
- [x] The character walks.
